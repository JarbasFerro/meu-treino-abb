# Best-In-Class Roadmap

This roadmap extends the core PWA upgrade with the larger product direction from `docs/deep-research-report.md`.

## Execution Loop

- Add duration choices for each day: 15, 30, and 50 minutes.
- Show smarter next-load suggestions based on clean completion and prior bests.
- Add warm-up calculation for weighted exercises.
- Add per-exercise history sheets with recent loads, notes, RPE, and PRs.

## Travel And Adaptability

- Add a compact equipment checklist for Hotel mode.
- Add replacement filters for no equipment, same equipment, and different equipment.
- Add travel-week templates that preserve the same training intent with fewer setup needs.

## Beginner Guidance

- Add lightweight cached form media for priority movements.
- Add technique-day variants with fewer sets and more instruction.
- Add movement-pattern education across squat, hinge, push, pull, carry, core, and mobility.

## Habit And Recovery

- Add cue planning: time, place, and fallback version.
- Add streak repair that treats low-energy sessions as valid and avoids shame language.
- Add optional reminders with calm coach-style copy.
- Add a recovery model for missed days that suggests the next best session without forcing catch-up volume.

## Progress And Ownership

- Add anchor-movement progression charts.
- Add core benchmark tracking.
- Add export bundles that include future media references and plan configuration.
- Add optional accountability export/share without feeds, leaderboards, or comparison defaults.

## Internal Quality

- Add browser-based regression tests for mobile viewports.
- Add PWA install/offline checks to the release routine.
- Add performance budget checks and split optional Firebase sync from the initial bundle.
